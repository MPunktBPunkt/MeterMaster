# MeterMaster

**Android-App zur Verwaltung von Versorgungszählern** — entwickelt für Vermieter und Hauseigentümer.

> 🇩🇪 German-language app for utility meter management (water, heat, gas, electricity).

---

## Features

- 📊 **Zählererfassung** — Heizung, Warmwasser, Kaltwasser, Gas, Strom, Gesamtwasser und mehr
- 🏠 **Mehrere Wohnungen** — beliebig viele Einheiten pro Haus, inkl. gemeinsamer Zähler
- 📷 **Foto-Belege** — Ablesungsfotos direkt in der App aufnehmen und speichern
- 📤 **Export & Backup** — JSON-Export, AES-256-verschlüsseltes Voll-Backup mit allen Einstellungen
- 📊 **Google Sheets** — direkte Synchronisation via Apps Script (Template inklusive)
- 🔌 **Smart Home Integration** — ioBroker, MQTT, InfluxDB, Home Assistant (alle optional, alle opt-in)
- 📱 **100 % offline** — keine Cloud, keine Accounts, keine Tracking
